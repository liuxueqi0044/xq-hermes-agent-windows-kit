# 自助版服务范围

## 包含

- 锁定版本的官方来源、文件名、SHA-256 和签名记录；
- 中文安装、首次配置、备份、更新、卸载和 FAQ 页面；
- 本地只读诊断工具；
- 一次基于脱敏诊断报告的文字答疑。

## 不包含

- 模型账号、订阅、Key、验证码或 API 费用；
- 远程控制、代输入凭据或代保管账号；
- 云服务器、托管、消息渠道、定制扩展和企业部署；
- 对第三方服务的可用性、费用、速度或回答质量作保证；
- 未经单独验收的功能支持。

## 提问方式

请描述系统版本、Hermes 版本、复现步骤和不含秘密的错误摘要。不要发送 Key、Token、Cookie、密码、邮箱、余额、会话正文或本地文件。
