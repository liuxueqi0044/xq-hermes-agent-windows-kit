# 提交问题前请准备

## 建议提供

- Windows 版本和系统架构；
- Hermes 版本和安装器文件名；
- 问题首次出现的时间；
- 可复现步骤和不含隐私的错误摘要；
- XQ 诊断工具生成的脱敏报告。

## 必须删除或遮挡

提交前检查报告、截图和日志，删除或遮挡 API Key、Token、Bearer 字样、Cookie、密码、邮箱、账户余额、授权码、SSH 信息、服务器地址、会话正文和用户文件内容。不要发送 `.env` 文件。

## 不要做的事

不要为了排错关闭 Defender、SmartScreen、防火墙或 UAC，不要执行来源不明的脚本，不要把生产数据复制到测试环境，也不要递归删除 Hermes 数据目录。

## 处理边界

XQ 可以协助本套件范围内的安装、版本核对、基础配置和脱敏诊断解读。账号、订阅、账单、配额、第三方服务故障和官方产品变更需要联系对应服务商或官方渠道。支持时间、次数和响应方式以购买时约定为准。
