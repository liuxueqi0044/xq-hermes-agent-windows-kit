# 远程基础安装服务范围

## 包含

- 在 Windows 11 x64 普通本地桌面环境安装 Hermes Desktop/CLI；
- 连接一个由买家本人拥有的模型服务；
- 跑通一次普通文本对话并运行基础检查；
- 处理一次安装过程内的基础报错。

## 用户必须在场

用户本人必须在场并亲自输入密码、验证码、OAuth 授权和 API Key。XQ 不接收、复制、保存或代填完整凭据。远程结束后退出远程软件，不保存无人值守密码。

## 不包含

- 代购或赠送模型 Key、账号、订阅和充值；
- 云端 7×24 小时运行或公网服务；
- 消息渠道、工作流定制、第三方扩展和多用户部署；
- 对第三方模型稳定性、配额和效果作保证。

## 完成标准

Desktop 能打开、版本命令有返回、用户自己的模型服务连接成功、完成一轮普通文本问答，且诊断没有阻断运行的错误。超出范围的需求需另行确认。
