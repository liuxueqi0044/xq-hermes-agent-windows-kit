# 跑通第一次对话

## 目标

本页只验证一件事：在本机使用你自己的模型服务完成一轮普通文本问答。扩展能力不属于首版基础验收，不要为了“先跑起来”同时改动网络暴露、自动任务或第三方扩展设置。

## 操作

1. 确认 Desktop 已打开，状态页没有正在进行的安装失败。
2. 确认当前模型路线已经完成登录或本机 Key 配置。
3. 新建普通对话，输入不含隐私的短句，例如：`请用三句话介绍 Windows 11。`
4. 等待模型返回，检查没有认证、余额、网络或模型名称错误。
5. 不要把包含账号、Key、聊天正文或本地文件的截图发给他人。

## 命令行复核

需要复核版本时，在 PowerShell 中运行：

```powershell
hermes --version
hermes doctor
```

`hermes doctor` 可能检查本地配置和认证状态。分享输出前先使用本包诊断工具的脱敏结果，不要直接复制未经检查的原始输出。

## 成功与失败

成功：Desktop 能打开、版本命令有返回、模型服务连接成功，并完成一轮普通文本问答；诊断没有阻断运行的错误。

失败：记录错误发生在哪一步、时间和不含秘密的错误摘要。先查看 FAQ，再生成本地诊断报告。模型服务的限额、账单、区域可用性和响应质量需要向对应服务商确认。

## 保护数据

首次对话使用无隐私测试文本。不要粘贴密码、身份证件、客户资料、生产日志、会话导出或本地文件。测试完成后按数据页面确认备份范围。
