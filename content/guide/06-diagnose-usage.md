# 诊断工具使用说明

## 用途和限制

Hermes-XQ-Diagnose.ps1 是本地只读检查工具，帮助整理 Windows、工具版本、磁盘空间、Hermes 路径和脱敏后的基础检查结果。它不联网、不上传、不修复、不安装依赖、不修改配置、不提权。

工具默认在临时隔离的 Hermes Home 中调用 `hermes doctor`，避免把真实环境中的认证元数据和会话信息当作普通诊断输入。它不会读取 `.env` 内容、对话正文、浏览器历史、保存的凭据或用户文件。

## 运行

在解压后的 `03-诊断工具` 目录打开普通 PowerShell 窗口，由用户选择输出位置并运行：

```powershell
.\Hermes-XQ-Diagnose.ps1 -OutputPath "$env:USERPROFILE\Desktop\Hermes-Diagnostic.txt"
```

如果工具版本提供交互式输出路径，请按提示选择本地文件。不要使用管理员窗口，也不要把报告写入共享目录。实际参数以随包脚本的帮助信息为准：

```powershell
Get-Help .\Hermes-XQ-Diagnose.ps1 -Full
```

## 报告如何阅读

每项会标记“正常 / 警告 / 未安装 / 无法检查”。报告可能显示 Windows 版本、架构、管理员状态、磁盘空间、可执行文件路径、工具版本、Hermes 根目录大小和脱敏结果。未安装的工具不代表本套件损坏。

提交前逐行检查，确认 Key、Token、Bearer、密码、Cookie、邮箱、授权码、服务器地址、会话正文和用户文件内容均未出现。发现疑似秘密时不要继续分享，先撤销或重置相关凭据，再联系服务商。

## 常见结果

- Hermes 未安装：先完成官方安装流程，再重新运行诊断。
- 命令超时：保留报告中的超时状态，不要反复提交原始输出；检查网络和官方服务状态。
- `doctor` 有警告：结合错误摘要和官方文档判断；诊断工具不会替你修改配置。
- 磁盘空间不足：先备份需要保留的数据，再按官方说明处理空间。

## 数据责任

报告只保存在你指定的本地路径。XQ 不会自动接收或上传它；分享前由用户负责完成脱敏。请勿复制生产环境数据到测试环境。
